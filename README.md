# Moments Calculator

## What is it?

Moments Calculator is a simple personal reflection tool designed to make time with the people you love more visible.

The idea is simple:

> We often think about how much time we have already spent with someone. This tool helps you think about how many moments may still remain.

Instead of treating time as an abstract number, the calculator turns an everyday relationship into an estimate you can actually see.

## What the calculator does

You enter information about a person you care about, such as:

- Their name
- Their current age
- Your age
- How often you see them
- How long you normally spend together
- An estimated lifespan or time horizon

The calculator then estimates the amount of time or number of future moments you may have together based on those inputs.

The result is an estimate, not a prediction.

## Why it exists

Time with people changes as life changes.

You may see someone frequently today, but work, college, moving, marriage, distance, health, or other responsibilities can change that pattern later.

The purpose of the calculator is not to create fear. It is to make the limited nature of time easier to notice.

A number can make something abstract feel concrete.

## How to use it

1. Choose someone who matters to you.
2. Enter the requested information as honestly as possible.
3. Review the estimated moments remaining.
4. Notice what the number makes you think about.
5. Use that awareness to decide whether you want to spend more intentional time together.

## Important limitation

The calculation is an estimate based entirely on the assumptions and information entered by the user.

It cannot predict:

- How long someone will live
- How often you will actually meet
- Future changes in your relationship
- Unexpected events
- The quality of the time you spend together

The result should therefore be treated as a reflection tool, not as a factual countdown.

## Privacy

The calculator is designed to work locally in the browser.

If the version you are using stores people or calculations in browser storage, that information remains in the browser unless the code is changed to send it to an external service.

Do not enter sensitive personal information that the calculator does not require.

## Resetting saved people

If the calculator includes saved people, use the reset or delete function when you want to remove them.

Clearing the browser's site data will also remove locally stored information if the application uses browser storage.

## Technology

The calculator is built as a lightweight web application using:

- HTML
- CSS
- JavaScript
- Browser local storage, where applicable

No backend is required for the basic version.

## Design philosophy

The interface is intentionally simple.

The goal is not to add more productivity features. The goal is to make one idea visible:

**Your time with the people you love is finite.**

Use the number as a reminder to be present, not as something to obsess over.
